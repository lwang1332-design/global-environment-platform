# 本地开源地图瓦片目录

平台支持本地 XYZ 栅格瓦片作为第二地图源，默认模板：

`./tiles/{z}/{x}/{y}.png`

要求：

- Web Mercator / EPSG:3857
- XYZ 切片规则
- 256×256 px
- 建议使用基于 OpenStreetMap / OpenMapTiles 等开放数据自行生成的离线瓦片
- 注意保留所采用数据集要求的署名与许可证信息

部署示例：

```
tiles/
  2/
    0/1.png
    1/1.png
  3/
    ...
```

网页会按以下顺序自动降级：

- 中国区域：天地图（已配置浏览器端 Key）→ 本地 XYZ → 在线 OSM
- 海外区域：本地 XYZ → 在线 OSM

如果不希望使用在线 OSM，可在管理员参数页的“地图数据源”中关闭“在线 OSM 兜底”。
