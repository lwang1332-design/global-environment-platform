# EA01–EA50 环境数据计算与质量规范 V3.2.4

日期：2026-10-24 | 数据字典唯一来源：`v2.7-metric-catalog.js` | 程序实现：`v2.7-health-v3.js`

## 数据获取
- ERA5 / Open-Meteo Archive：项目经纬度，最近1、3、5年，结束于调用日约10天之前；按自然年分块、UTC小时对齐。
- ERA5-Land：同期风阵、雪深补充；补充接口失败不伪造雪深。
- CAMS Global / Open-Meteo Air Quality：近90天PM10、PM2.5、Dust、SO₂、NO₂、Sea Salt Aerosol。不能当成历史1/3/5年污染物代表值。
- Open-Meteo Elevation：项目地表高程。接口失败标为缺测。
- 缺乏可靠公开来源的专项指标保持null与UNKNOWN，不以零值替代。

## 计算口径
- 所有分位值：有效数值排序后线性插值，`p*(n-1)`位置。
- 每日聚合：UTC连续24小时，至少18有效小时，分别统计日最高/最低、日温差、日降雨量。
- 年化：`事件数/有效小时×8760`，当前为覆盖率外推，数据不具代表性时应禁止工程冻结。
- EA01：有效日最高温P99；EA02：有效小时温度最低值。
- EA14：10m风速≥12m/s 且 rain≥0.1mm/h 同小时数年化，为工程代理。
- EA16–EA20：统一使用`rain`；EA17最大日降雨，EA18含零雨小时降雨P99，EA19`rain × wind_speed_10m` P99。不能与`precipitation`混用。
- EA23：RH>80%时间比例，仅为湿润潜势代理，**非** ISO 9223 正式TOW。
- EA31：ERA5-Land雪深 m→cm；EA34：完整冻结→解冻循环，属空气温度代理。
- EA37/38：气压hPa/10转换kPa；EA39/40：根据同期p、T、RH计算湿空气密度。
- EA47：短波辐照度小时P99，不能与旧版rad95阈值直接混用。

## 统一数据关联
`EA_METRIC_CATALOG`保证50项唯一ID、名称、单位、公式、来源、版本；`envHealthV31.fields`集中保存当次环境值、原始来源、计算说明、质量、统计期、有效样本数和coverage。
同口径旧引擎输入从02新记录同步：t99、tmin、rhAvg、rainYear、snowHours、alt、so2；最大1小时降雨单独基于相同rain原始数据计算。不同口径的wind95、rad95、PM10/Dust/盐气溶胶均值，以及rh90，保留明确独立变量，严禁误把P95/P99或均值混合使用。

## 风险与缺失值
- 项目核心环境参数缺失时，旧模型采用保守占位，`__envMissing`记录缺测；新版按指标分为LOW/MEDIUM/HIGH/UNKNOWN/UNRATED。
- 类别风险聚合：HIGH优先、MEDIUM次之；只要仍存在UNKNOWN或UNRATED，不能显示整个类别已确认LOW。
- 规则要求管理员批准并提供阈值依据；没有批准规则的指标为UNRATED。

## 当前必须保留的专项缺口
EA08–EA10凝露、EA15同期风沙、EA21盐沉积、EA24/25腐蚀、EA29/30沙尘暴事件、EA42/43/45有害气体、EA46植被、EA48台风、EA49雷电、EA50生物环境均不可无凭据估算。

2. 9场景工程标定及实际项目误差分析；

4. 某些旧场景特征保留统计口径单独运行，尚未消除所有旧版风险与计算字段。
所以此版本为**V3.2.4计算口径统一与安全增强版**，不宣称所有专项工程模型已经验证。
